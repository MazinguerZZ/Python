# 03 – Invertir el Hechizo

Un mago malvado ha lanzado un hechizo sobre el pueblo y ha invertido todas las palabras. Como aventurero, necesitas escribir una función que revierta cualquier lista de palabras para romper el hechizo.

---

| Valor de Entrada                        | Valor Esperado                      |
|-----------------------------------------|-------------------------------------|
| `(["hola", "mundo"])`                   | `"['mundo', 'hola']"`               |
| `([])`                                  | `"[]"`                              |
| `(["dragón", "tesoro", "mazmorra"])`    | `"['mazmorra', 'tesoro', 'dragón']"` |

> - **Valor de Entrada:** El valor de entrada de la prueba.
> - **Valor Esperado:** El valor esperado de respuesta de la prueba.
