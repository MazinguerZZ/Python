# 06 – Buscar el Tesoro Más Valioso

Encuentras un mapa que enumera varios cofres con sus respectivos valores en oro. Escribe una función que reciba una lista de valores y devuelva el mayor valor. Si la lista está vacía, debe devolver -1.

---

| Valor de Entrada          | Valor Esperado |
|---------------------------|----------------|
| `([100, 200, 50])`        | `"200"`        |
| `([])`                    | `"-1"`         |
| `([500, 800, 800, 1000])` | `"1000"`       |

> - **Valor de Entrada:** El valor de entrada de la prueba.
> - **Valor Esperado:** El valor esperado de respuesta de la prueba.
