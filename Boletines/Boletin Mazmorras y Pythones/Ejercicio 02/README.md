# 02 – Abrir el Cofre Mágico

Eres un aventurero que ha encontrado un cofre mágico en las profundidades de una mazmorra. El cofre se abrirá si introduces un código secreto que es la suma de dos números grabados en una piedra cercana. Crea una función que reciba estos dos números y devuelva el código correcto para abrir el cofre.

---

| Valor de Entrada | Valor Esperado |
|------------------|----------------|
| `(3, 5)`         | `"8"`          |
| `(10, -4)`       | `"6"`          |
| `(0, 0)`         | `"0"`          |

> - **Valor de Entrada:** El valor de entrada de la prueba.
> - **Valor Esperado:** El valor esperado de respuesta de la prueba.
