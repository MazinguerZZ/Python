# 28 – Crear un Mapa de la Mazmorra

Debes crear una representación del mapa de la mazmorra. Escribe una función que reciba las dimensiones del mapa (filas y columnas) y devuelva una matriz (lista de listas) representando el mapa, donde cada celda contiene un punto `'.'` indicando un espacio vacío.

---

| Valor de Entrada | Valor Esperado |
|------------------|----------------|
| `(3, 4)` | `"[['.', '.', '.', '.'], ['.', '.', '.', '.'], ['.', '.', '.', '.']]"` |
| `(2, 2)` | `"[['.', '.'], ['.', '.']]"` |
| `(1, 5)` | `"[['.', '.', '.', '.', '.']]"` |

> - **Valor de Entrada:** El valor de entrada de la prueba.
> - **Valor Esperado:** El valor esperado de respuesta de la prueba.
