# 20 – Bromas Mágicas y Caóticas

Escribe una función que reciba el nivel de humor de un héroe y el tipo de broma que intenta (por ejemplo: `'chiste'`, `'troleo'`, `'picar'`). Si el nivel de humor es lo suficientemente alto, la broma será un éxito épico. Si el humor es bajo (< 6), la broma será un fracaso. Devuelve un mensaje con el resultado.

---

| Valor de Entrada     | Valor Esperado                |
|----------------------|-------------------------------|
| `(7, "chiste")`      | `"Éxito épico - chiste"`      |
| `(2, "troleo")`      | `"Fracaso total - troleo"`    |
| `(10, "picar")`      | `"Éxito épico - picar"`       |
| `(0, "chiste")`      | `"Fracaso total - chiste"`    |

> - **Valor de Entrada:** El valor de entrada de la prueba.
> - **Valor Esperado:** El valor esperado de respuesta de la prueba.
