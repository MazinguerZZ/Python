# 23 – Descifrar el Código Secreto

Un anciano te entrega un pergamino con un código cifrado. El código consiste en una cadena de números separados por comas. Cada número representa una letra del alfabeto (A=1, B=2, ..., Z=26). Escribe una función que decodifique el código y devuelva el mensaje secreto.

---

| Valor de Entrada          | Valor Esperado |
|---------------------------|----------------|
| `("8, 5, 12, 12, 15")`    | `"HELLO"`      |
| `("23, 15, 18, 12, 4")`   | `"WORLD"`      |
| `("1, 2, 3")`             | `"ABC"`        |

> - **Valor de Entrada:** El valor de entrada de la prueba.
> - **Valor Esperado:** El valor esperado de respuesta de la prueba.
