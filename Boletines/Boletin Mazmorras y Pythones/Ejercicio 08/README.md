# 08 – Calcular el Poder del Héroe

El héroe ha obtenido una serie de objetos mágicos, cada uno con un valor de poder. Escribe una función que reciba una lista de valores de poder y devuelva la suma total. Si la lista está vacía, debe devolver 0.

---

| Valor de Entrada   | Valor Esperado |
|--------------------|----------------|
| `([10, 20, 30])`   | `"60"`         |
| `([])`             | `"0"`          |
| `([5, -5, 15])`    | `"15"`         |

> - **Valor de Entrada:** El valor de entrada de la prueba.
> - **Valor Esperado:** El valor esperado de respuesta de la prueba.
