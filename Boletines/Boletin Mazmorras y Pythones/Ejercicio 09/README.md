# 09 – Identificar Números Mágicos

En una mazmorra hay números mágicos. Un número es mágico si es divisible por 3 pero no por 5. Escribe una función que reciba una lista de números y devuelva una lista solo con los números mágicos.

---

| Valor de Entrada            | Valor Esperado   |
|-----------------------------|------------------|
| `([3, 5, 15, 9, 7])`        | `"[3, 9]"`       |
| `([5, 10, 20])`             | `"[]"`           |
| `([30, 9, 21, 45, 27])`     | `"[9, 21, 27]"`  |

> - **Valor de Entrada:** El valor de entrada de la prueba.
> - **Valor Esperado:** El valor esperado de respuesta de la prueba.
