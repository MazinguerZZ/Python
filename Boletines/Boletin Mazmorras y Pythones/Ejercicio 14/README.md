# 14 – Identificar Trampas en la Mazmorra

En una mazmorra hay trampas ocultas. Una trampa se identifica si su valor es negativo. Escribe una función que reciba una lista de valores y devuelva una lista solo con las trampas.

---

| Valor de Entrada              | Valor Esperado       |
|-------------------------------|----------------------|
| `([3, -5, 15, -9, 7])`        | `"[-5, -9]"`         |
| `([5, 10, 20])`               | `"[]"`               |
| `([-30, 9, -21, 45, -27])`    | `"[-30, -21, -27]"`  |

> - **Valor de Entrada:** El valor de entrada de la prueba.
> - **Valor Esperado:** El valor esperado de respuesta de la prueba.
