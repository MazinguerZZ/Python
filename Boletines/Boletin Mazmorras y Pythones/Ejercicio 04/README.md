# 04 – Resolver el Acertijo de la Puerta

Una puerta bloquea tu paso y solo se abrirá si resuelves un acertijo matemático. La puerta pide que multipliques dos números, pero si alguno es negativo, debes devolver cero. Escribe una función que resuelva este acertijo.

---

| Valor de Entrada | Valor Esperado |
|------------------|----------------|
| `(3, 4)`         | `"12"`         |
| `(-3, 5)`        | `"0"`          |
| `(0, 7)`         | `"0"`          |

> - **Valor de Entrada:** El valor de entrada de la prueba.
> - **Valor Esperado:** El valor esperado de respuesta de la prueba.
