# Kata: ¡La Rana Bocazas!
**Dificultad:** 1/8

---

## 📝 Enunciado

La rana bocazas siente una curiosidad especial por los hábitos alimenticios de otras criaturas y no para de preguntar qué les gusta comer. Pero un día se encuentra con el caimán, ¡que adora comerse ranas bocazas! Al verlo, la rana pone una boca pequeñita.

Completa el método `mouth_size` que recibe un argumento `animal`. Si el animal es un `alligator` (sin distinguir mayúsculas/minúsculas) devuelve `"small"`, en cualquier otro caso devuelve `"wide"`.
