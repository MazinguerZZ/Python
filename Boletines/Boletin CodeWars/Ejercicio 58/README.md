# Kata: Encuentra el Número Único
**Dificultad:** 3/8

---

## 📝 Enunciado

Completa la función que devuelve el único número que aparece una sola vez en un array.

Todos los números del array desordenado aparecen dos veces, excepto el que debes encontrar. Los números son siempre enteros válidos entre 1 y 2.147.483.647, por lo que no es necesario comprobar tipos ni errores. El array contiene al menos un número y puede contener millones de ellos, así que asegúrate de que tu solución esté optimizada para la velocidad.

### Ejemplo

```
[ 1, 8, 4, 4, 6, 1, 8 ]  -->  6
```
