# Kata: ¿Estás Tocando el Banjo?
**Dificultad:** 1/8

---

## 📝 Enunciado

Crea una función que responda a la pregunta "¿Estás tocando el banjo?". Si tu nombre empieza por la letra `R` o `r`, ¡estás tocando el banjo!

La función recibe un nombre como único argumento y devuelve una de las siguientes cadenas:

```
name + " plays banjo"
name + " does not play banjo"
```

Los nombres proporcionados siempre serán cadenas válidas.
