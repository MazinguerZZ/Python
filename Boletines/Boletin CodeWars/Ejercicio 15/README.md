# Kata: ¡Convierte una Cadena a Número!
**Dificultad:** 1/8

---

## 📝 Enunciado

Necesitamos una función que transforme una cadena de texto en un número. 

> **Nota:** No te preocupes, todas las entradas serán cadenas de texto y cada una es una representación válida de un número entero.

### Ejemplos

```
"1234" --> 1234
"605"  --> 605
"1405" --> 1405
"-7"   --> -7
```
