# Kata: Plural
**Dificultad:** 1/8

---

## 📝 Enunciado

Necesitamos una función sencilla que determine si se debe usar el plural o no. Debe recibir un número y devolver `true` si ese número requiere plural o `false` si no.

Esto sería útil al imprimir cadenas como `5 minutos`, `14 manzanas` o `1 sol`.

Solo debes tener en cuenta las reglas gramaticales del inglés: cualquier cantidad que no sea exactamente uno es plural.

> **Nota:** Todos los valores serán enteros o decimales positivos, o cero.
