# Kata: Unos y Ceros
**Dificultad:** 2/8

---

## 📝 Enunciado

Dado un array de unos y ceros, convierte el valor binario equivalente a un entero.

Por ejemplo: `[0, 0, 0, 1]` se trata como `0001`, que es la representación binaria de `1`.

### Ejemplos

```
[0, 0, 0, 1]  ==>  1
[0, 0, 1, 0]  ==>  2
[0, 1, 0, 1]  ==>  5
[1, 0, 0, 1]  ==>  9
[0, 1, 1, 0]  ==>  6
[1, 1, 1, 1]  ==>  15
[1, 0, 1, 1]  ==>  11
```

> **Nota:** Los arrays pueden tener longitudes variables, no solo de 4 elementos.
