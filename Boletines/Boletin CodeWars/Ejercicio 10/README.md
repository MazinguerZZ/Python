# Kata: Saltamontes - Libro de Notas
**Dificultad:** 1/8

---

## 📝 Enunciado

Completa la función para que calcule la media de las tres notas que se le pasan y devuelva la letra correspondiente a esa calificación.

| Nota numérica | Letra |
|---|---|
| 90 <= nota <= 100 | 'A' |
| 80 <= nota < 90 | 'B' |
| 70 <= nota < 80 | 'C' |
| 60 <= nota < 70 | 'D' |
| 0 <= nota < 60 | 'F' |

> **Nota:** Los valores siempre están entre 0 y 100. No es necesario comprobar valores negativos ni mayores que 100.
