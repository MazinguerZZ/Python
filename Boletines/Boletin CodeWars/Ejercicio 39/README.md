# Kata: Saltamontes - Función Goles de Messi
**Dificultad:** 1/8

---

## 📝 Enunciado

Messi es un jugador de fútbol con goles en tres competiciones:

* LaLiga
* Copa del Rey
* Champions

Completa la función para que devuelva el total de goles en las tres competiciones.

> **Nota:** La entrada siempre será válida.

### Ejemplo

```
5, 10, 2  -->  17
```
