# Kata: Saltamontes - Mensaje Personalizado
**Dificultad:** 1/8

---

## 📝 Enunciado

Crea una función que devuelva un saludo personalizado. La función recibe dos parámetros: `name` y `owner`.

Usa condicionales para devolver el mensaje adecuado:

| Caso | Devuelve |
|---|---|
| `name` es igual a `owner` | `'Hello boss'` |
| en cualquier otro caso | `'Hello guest'` |
