# Kata: Saltamontes - Sumatoria
**Dificultad:** 1/8

---

## 📝 Enunciado

Escribe un programa que calcule la suma de todos los números del 1 al `num` (ambos inclusive). El número siempre será un entero positivo mayor que 0. Tu función solo necesita devolver el resultado.

### Ejemplos

```
2 -> 3  (1 + 2)
8 -> 36 (1 + 2 + 3 + 4 + 5 + 6 + 7 + 8)
```
