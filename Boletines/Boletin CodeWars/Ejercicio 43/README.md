# Kata: Una Aguja en el Pajar
**Dificultad:** 1/8

---

## 📝 Enunciado

¿Puedes encontrar la aguja en el pajar?

Escribe una función `findNeedle()` que reciba un array lleno de basura pero que contiene una `"needle"`. La función debe devolver un mensaje indicando en qué posición se encontró.

### Ejemplo

```
["hay", "junk", "hay", "hay", "moreJunk", "needle", "randomJunk"]
--> "found the needle at position 5"
```
