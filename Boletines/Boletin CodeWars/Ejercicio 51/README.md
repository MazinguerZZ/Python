# Kata: ¿Va a Sobrevivir?
**Dificultad:** 1/8

---

## 📝 Enunciado

Un héroe se dirige al castillo para completar su misión, pero le han avisado de que está rodeado de dragones. Cada dragón necesita 2 balas para ser derrotado.

Dados el número de balas que lleva el héroe y el número de dragones que debe enfrentarse, determina si sobrevivirá.

Devuelve `true` si sobrevive, `false` en caso contrario.
