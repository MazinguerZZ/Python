# Kata: ¡Hola, Nombre o Mundo!
**Dificultad:** 1/8

---

## 📝 Enunciado

Define un método `hello` que devuelva `"Hello, Name!"` para un `name` dado, o `"Hello, World!"` si no se proporciona nombre (o se pasa una cadena vacía).

Se asume que `name` es una cadena de texto y se corrigen posibles errores del usuario devolviendo el nombre con la primera letra en mayúscula (Xxxx).

### Ejemplos

```
name = "john"  => "Hello, John!"
name = "aliCE" => "Hello, Alice!"
name = ""      => "Hello, World!"
name no dado   => "Hello, World!"
```
