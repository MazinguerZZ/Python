# Kata: Encuentra el Entero Más Pequeño del Array
**Dificultad:** 1/8

---

## 📝 Enunciado

Dado un array de enteros, tu solución debe encontrar el número más pequeño.

### Ejemplos

* Dado `[34, 15, 88, 2]` devuelve `2`
* Dado `[34, -345, -1, 100]` devuelve `-345`

> **Nota:** Puedes asumir que el array nunca estará vacío.
