# Kata: Serie Principiantes #4 Cucaracha
**Dificultad:** 1/8

---

## 📝 Enunciado

La cucaracha es uno de los insectos más rápidos. Escribe una función que reciba su velocidad en km/h y la devuelva en cm/s, redondeada hacia abajo (floor).

### Ejemplo

```
1.08 --> 30
```

> **Nota:** La entrada es un número real >= 0 y el resultado debe ser un entero.
