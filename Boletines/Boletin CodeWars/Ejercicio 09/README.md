# Kata: Repetir Cadena
**Dificultad:** 1/8

---

## 📝 Enunciado

Escribe una función que acepte un entero no negativo `n` y una cadena de texto `s` como parámetros, y devuelva la cadena `s` repetida exactamente `n` veces.

### Ejemplos

```
6, "I"     -> "IIIIII"
5, "Hello" -> "HelloHelloHelloHelloHello"
```
