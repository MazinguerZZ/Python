# Kata: Número de Teléfono Válido
**Dificultad:** 3/8

---

## 📝 Enunciado

Escribe una función que acepte una cadena de texto y devuelva `true` si tiene el formato de un número de teléfono válido.

El único formato válido es: `(123) 456-7890` (sin olvidar el espacio después del paréntesis de cierre).

### Ejemplos

```
"(123) 456-7890"  => true
"(1111)555 2345"  => false
"(098) 123 4567"  => false
```
