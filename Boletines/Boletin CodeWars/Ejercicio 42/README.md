# Kata: Convertir a Binario
**Dificultad:** 1/8

---

## 📝 Enunciado

Dado un entero no negativo `b`, escribe una función que devuelva un entero `d` tal que la representación binaria de `b` sea igual a la representación decimal de `d`.

### Ejemplos

```
n = 1   -->  1
n = 5   -->  101
n = 11  -->  1011
```
