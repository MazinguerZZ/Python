# Kata: Calculadora Simple
**Dificultad:** 1/8

---

## 📝 Enunciado

Crea una calculadora simple que devuelva el resultado de sumar, restar, multiplicar o dividir dos números.

Tu función aceptará tres argumentos: el primero y el segundo deben ser números, y el tercero un signo que indica la operación a realizar.

- Si alguno de los dos primeros argumentos no es un número, devuelve `"unknown value"`.
- Si la operación no es ninguna de las cuatro básicas, devuelve `"unknown value"`.

### Ejemplos

```
1, 2, "+"  -->  3
1, 2, "&"  -->  "unknown value"
1, "k", "*"  -->  "unknown value"
```
