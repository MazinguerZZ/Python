# Kata: ¿Está la Cadena en Mayúsculas?
**Dificultad:** 1/8

---

## 📝 Enunciado

Crea un método que compruebe si una cadena de texto está completamente en MAYÚSCULAS.

### Ejemplos

```
"c"                      -> False
"C"                      -> True
"hello I AM DONALD"      -> False
"HELLO I AM DONALD"      -> True
"ACSKLDFJSgSKLDFJSKLDFJ" -> False
"ACSKLDFJSGSKLDFJSKLDFJ" -> True
```

> **Nota:** Una cadena se considera en MAYÚSCULAS cuando no contiene ninguna letra minúscula. Por tanto, una cadena sin letras se considera trivialmente en mayúsculas.
