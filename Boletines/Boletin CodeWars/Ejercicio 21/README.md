# Kata: Elimina los Espacios
**Dificultad:** 1/8

---

## 📝 Enunciado

Escribe una función que elimine todos los espacios de la cadena de texto y devuelva el resultado.

### Ejemplos

```
"8 j 8   mBliB8g  imjB8B8  jl  B" -> "8j8mBliB8gimjB8B8jlB"
"8 8 Bi fk8h B 8 BB8B B B  B888 c hl8 BhB fd" -> "88Bifk8hB8BB8BBBB888chl8BhBfd"
"8aaaaa dddd r     " -> "8aaaaaddddr"
```
