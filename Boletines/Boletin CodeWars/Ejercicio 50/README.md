# Kata: Trimestre del Año
**Dificultad:** 1/8

---

## 📝 Enunciado

Dado un mes como entero del 1 al 12, devuelve a qué trimestre del año pertenece.

### Ejemplos

* Mes 2 (febrero) → trimestre 1
* Mes 6 (junio) → trimestre 2
* Mes 11 (noviembre) → trimestre 4

> **Restricción:** `1 <= mes <= 12`
