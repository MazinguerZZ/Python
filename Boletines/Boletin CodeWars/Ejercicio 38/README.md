# Kata: Corrige los Errores del Software de Reconocimiento de Caracteres
**Dificultad:** 1/8

---

## 📝 Enunciado

El software de reconocimiento de caracteres se usa ampliamente para digitalizar textos impresos. Sin embargo, especialmente en documentos antiguos escritos a máquina, suele cometer errores.

Tu tarea es corregir los errores en el texto digitalizado. Solo debes manejar los siguientes fallos:

* `S` interpretada como `5`
* `O` interpretada como `0`
* `I` interpretada como `1`

> **Nota:** Los casos de prueba solo contienen números por error, no números reales.
