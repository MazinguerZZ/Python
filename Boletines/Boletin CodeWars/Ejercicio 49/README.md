# Kata: ¿Amigo o Enemigo?
**Dificultad:** 2/8

---

## 📝 Enunciado

Crea un programa que filtre una lista de nombres y devuelva solo los de tus amigos.

Si un nombre tiene exactamente 4 letras, ¡seguro que es amigo tuyo! En caso contrario, no lo es.

### Ejemplos

```
["Ryan", "Kieran", "Jason", "Yous"]  -->  ["Ryan", "Yous"]
["Peter", "Stephen", "Joe"]          -->  []
```

> **Nota:** Las cadenas solo contendrán letras. Mantén el orden original de los nombres en la salida.
