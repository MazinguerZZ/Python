# Kata: Aplasta la Frase
**Dificultad:** 1/8

---

## 📝 Enunciado

Escribe una función que reciba un array de palabras y las una en una frase, devolviéndola como cadena de texto. No hace falta sanear las palabras ni añadir puntuación, pero sí debes añadir un espacio entre cada palabra. ¡Cuidado, no debe haber espacios al principio ni al final!

### Ejemplo

```
['hello', 'world', 'this', 'is', 'great']  =>  'hello world this is great'
```

### Suposiciones

* Puedes asumir que solo se te pasan palabras.
* No puedes asumir el tamaño del array.
* Puedes asumir que siempre recibes un array.
