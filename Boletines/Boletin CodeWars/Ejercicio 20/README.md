# Kata: Alfabeto Polaco
**Dificultad:** 1/8

---

## 📝 Enunciado

El alfabeto polaco tiene 32 letras: 9 vocales y 23 consonantes.

Tu tarea es sustituir las letras con diacríticos por sus equivalentes sin acento:

```
ą -> a
ć -> c
ę -> e
ł -> l
ń -> n
ó -> o
ś -> s
ź -> z
ż -> z
```

Y devolver la cadena de texto sin letras polacas.

### Ejemplo

```
"Jędrzej Błądziński"  -->  "Jedrzej Bladzinski"
```
