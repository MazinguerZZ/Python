# Kata: Elimina el Primer y Último Carácter
**Dificultad:** 1/8

---

## 📝 Enunciado

Tu objetivo es escribir una función que elimine el primer y el último carácter de una cadena de texto.

> **Importante:** La función debe manejar cadenas de cualquier longitud `≥ 2`. Para cadenas de exactamente `2` caracteres, devuelve una cadena vacía.

### Ejemplos

```
'eloquent' --> 'loquen'
'country'  --> 'ountr'
'person'   --> 'erso'
'ab'       --> ''
'xyz'      --> 'y'
```

### Requisitos

* La cadena de entrada siempre tendrá al menos 2 caracteres
* Para cadenas de exactamente 2 caracteres, devuelve una cadena vacía
* Para cadenas de 3 o más caracteres, elimina el primero y el último
* La función debe manejar letras, números y caracteres especiales
