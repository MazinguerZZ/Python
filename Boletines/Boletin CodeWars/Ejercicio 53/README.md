# Kata: Encuentra el Número Único
**Dificultad:** 3/8

---

## 📝 Enunciado

Hay un array con varios números. Todos son iguales excepto uno. ¡Encuéntralo!

### Ejemplos

```python
find_uniq([1, 1, 1, 2, 1, 1])  == 2
find_uniq([0, 0, 0.55, 0, 0])  == 0.55
```

> **Notas:** Se garantiza que el array tiene al menos 3 números. Los tests incluyen arrays muy grandes, así que ten en cuenta el rendimiento.

> **Serie:** Este es el primer kata de una serie de 3: Find the unique number → Find the unique string → Find The Unique.
