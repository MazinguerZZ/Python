# Kata: ¿Par o Impar?
**Dificultad:** 2/8

---

## 📝 Enunciado

Dada una lista de enteros, determina si la suma de sus elementos es par o impar.

Da tu respuesta como una cadena de texto que sea `"odd"` o `"even"`.

Si el array de entrada está vacío, considéralo como `[0]` (array con un cero).

### Ejemplos

```
Input: [0]        →  "even"
Input: [0, 1, 4]  →  "odd"
Input: [0, -1, -5]  →  "even"
```
