# Boletín 5 — Ejercicios genéricos de programación

> Temas: vectores, arrays, listas y estructuras complejas similares
> Autor: José María Morales Vázquez

---

## Ejercicio 1 — Lotería primitiva
Escribir un programa que genere seis números aleatorios entre el 1 y el 49 sin que ninguno esté repetido (simulando una lotería primitiva).

## Ejercicio 2 — Divisores comunes
Hacer un programa que permita calcular todos los divisores comunes a dos números.

## Ejercicio 3 — Contar palabras
Escribir un programa que cuente las palabras de una frase introducida por teclado. Las palabras pueden estar separadas por más de un espacio, pero siempre debe haber al menos uno. Los signos de puntuación no se tienen en cuenta como separadores.

## Ejercicio 4 — Palabras con cuatro o más vocales diferentes
Escribir un programa que pida una cadena por teclado y cuente cuántas palabras contienen cuatro o más vocales distintas. Las vocales en mayúsculas y minúsculas se consideran iguales; no hay vocales acentuadas.

Ejemplo: `"Crisis constitucional por culpa del murcielago guineoecuatorial"` → 3

## Ejercicio 5 — Estadísticas de 100 números aleatorios
Generar 100 números aleatorios entre 1 y 50 (ambos inclusive) y obtener:
- El mayor
- El menor
- El que más veces se repite (y cuántas veces)

## Ejercicio 6 — Frecuencia de cifras en un número
Contar el número de veces que se repite cada cifra (0–9) en un número dado.

Ejemplo: `885210003` → tres 0, un 1, un 2, un 5 y dos 8
