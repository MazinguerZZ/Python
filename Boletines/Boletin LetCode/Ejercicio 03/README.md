# P3. Máximo de Unos Consecutivos

**Dificultad:** Fácil

Dado un array binario `nums`, devuelve el número máximo de `1`'s consecutivos en el array.

---

**Ejemplo 1:**

```
Input:  nums = [1,1,0,1,1,1]
Output: 3
Explicación: Los dos primeros o los tres últimos dígitos son 1s consecutivos. El máximo es 3.
```

**Ejemplo 2:**

```
Input:  nums = [1,0,1,1,0,1]
Output: 2
```

---

**Restricciones:**

- `1 <= nums.length <= 10^5`
- `nums[i]` es `0` o `1`
