# 69. Sqrt(x)

---

## Descripción

Dado un entero no negativo `x`, devuelve la raíz cuadrada de `x` redondeada hacia abajo al entero más cercano. El entero devuelto también debe ser no negativo.

**No puedes usar ninguna función u operador de exponenciación integrado.**

* Por ejemplo, no uses `pow(x, 0.5)` en C++ ni `x ** 0.5` en Python.

---

## Ejemplos

**Ejemplo 1:**
```
Entrada: x = 4
Salida: 2
Explicación: La raíz cuadrada de 4 es 2, por lo que se devuelve 2.
```

**Ejemplo 2:**
```
Entrada: x = 8
Salida: 2
Explicación: La raíz cuadrada de 8 es 2.82842..., y como se redondea
hacia abajo al entero más cercano, se devuelve 2.
```
