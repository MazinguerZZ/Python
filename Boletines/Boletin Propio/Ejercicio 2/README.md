# 709. A Minúsculas

Dada una cadena `s`, devuelve la cadena después de reemplazar cada letra mayúscula por la misma letra en minúscula.

**Ejemplo 1:**

```
Entrada: s = "Hello"
Salida: "hello"
```

**Ejemplo 2:**

```
Entrada: s = "here"
Salida: "here"
```

**Ejemplo 3:**

```
Entrada: s = "LOVELY"
Salida: "lovely"
```
